# TAKT Atelier Studio

Plannings chemin de fer et spatio-temporels pour le chantier, calculés automatiquement à partir de vos zones et de votre train de travaux. Windows 10 et 11. Sans compte, sans abonnement, sans connexion.

1. Téléchargement : onglet [Releases](https://github.com/MxMine/takt-atelier/releases) (installateur, version portable et manuel PDF)
2. Page du projet : https://mxmine.github.io/takt-atelier
3. Politique de confidentialité : https://mxmine.github.io/takt-atelier/confidentialite.html
4. Code source de chaque version : onglet [Releases](https://github.com/MxMine/takt-atelier/releases) (fichier `TAKT-Atelier-<version>-sources.zip`)
5. Contact et signalements : davidpercot@outlook.fr

Le logiciel n'est pas encore signé. Windows peut afficher un avertissement à l'installation et le Contrôle intelligent des applications, s'il est actif, bloque l'installation et le lancement.
